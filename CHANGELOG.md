# Changelog

## 1.0.0-rc.1

This release candidate replaces the 0.0.15 global API with root-scoped instances.

- Add typed promise-based navigation, refresh, and idempotent teardown.
- Support independent embedded instances, mixed-height sections, resize observation, and safe empty states.
- Correct index validation, transition completion, event details, gesture normalization, overflow boundaries, and URL history.
- Add semantic navigation, inert inactive sections, focus management, reduced motion, and safe text labels.
- Publish explicit JavaScript, CSS, and declaration exports.
- Add regression/browser/consumer tests, examples, contributor documentation, and CI/release workflows.

See README migration notes. Stable 1.0 remains subject to the manual checks in CONTRIBUTING.md.
